女生对重复低难度工作的忍耐度更高

重复性工作的专注保持力，是女性相对显著的生理优势。

心理两性

取舍

  • 顶部最安静：默认看不到标签，只看到"当前在看什么"。
  • 和列表卡片上的小标签呼应：顶部是"筛"，卡片是"标"。
  • 代价最大的是发现性：新访客可能完全不知道有标签体系。
  • 浮层里要放搜索 + 多选 + 清除，交互最重的一块。
代价：把"逛标签"这件事藏起来了。适合以搜索/时间线为主的用法，不适合把标签当导航。

横向对比

方案顶部高度标签可见性与原创页同构改动成本
现状 · 标签卡 ~110px（展开 20+ 行） 高 ✗ 挤不进频道条 —
T1 左栏筛选 0（移到侧栏） 中（9 个 + 搜索 + 全部） ✓ 完全一致 中：短句/人物/对话加两栏
T2 单行 + 更多 36px 中（前 5 个 + 浮层） ✓ 顶部一致，多一层细条 小：只改筛选组件
T3 已选 + 筛选 36px 低（要点开） ✓ 中：浮层要写搜索/多选

我选 T1。理由很直接：文章页的左侧主题栏已经是这个形态，把它推广到短句 / 人物 / 对话， 四个频道就变成完全一致的结构 —— 刊头 → 频道条 → 【筛选左栏 ｜ 列表】。

这样频道条放进来的成本是"一次布局统一"，不是"再加一层"：标签的总量没变，只是从横着铺变成竖着排。 296 个标签也有了归宿：侧栏只露前 9 个（按数量排序），搜索框负责精确查找，「全部 296 个标签」留着浏览入口。

T2 是 T1 的退路：如果不想动布局，就把标签压成一行 + 浮层，代价是常用标签变难点了。 T3 我不建议：它把标签体系藏得太深，而标签恰好是这个博客里最像"内容索引"的东西。

顺带一个问题：四个频道的筛选维度名字不一样（主题 / 标签 / 领域 / 话题），侧栏标题要不要统一成「筛选」？ 我倾向于保留各自的叫法 —— 它们本来就不是一回事。

设计稿占位：所有交互均为死链；浮层为静态展开示意；颜色 / 圆角 / 字体 token 与 src/styles/global.css 一致。
