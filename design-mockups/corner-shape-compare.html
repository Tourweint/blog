Design Decision Preview

圆角曲线：1/4 圆 → 贝塞尔（squircle）

下面每一组都是「左 = 现在的 1/4 圆，右 = 换成连续曲率曲线后的样子」。 拖动顶部滑块可以调曲线强度；勾选「整页预览」可以模拟全站换完后的整体观感。

1 = 1/4 圆（和左边相同） · 2 = 标准 squircle（iOS 图标同款） · 越大越「方」 检测中…

① 曲线本体：为什么它更顺

同一个圆角半径下两条曲线的对比。阴影区域是两条线之间的差——差得不多，但每一处衔接的手感不同。

  • 1/4 圆（墨色）：曲率处处相同，与直边相接的一瞬间曲率从 0 直接跳到最大——交界处有一道肉眼可感的「折点」，圆角越大事越明显。
  • 超椭圆（靛青）：与直边相接处曲率恰好为 0，然后随弧长缓慢长到最大——就是你说的「从 0 开始慢慢长」，整条线没有突变点，看起来更顺。
  • CSS 规范里这条曲线的正式名字是 superellipse(2)，关键字 squircle 就是它；日常俗称「iOS 连续曲率圆角」。
  • 拖动顶部滑块：拖到 1 时两条线重合（就是现状），往右拖超椭圆越来越「方」。

② 站点组件对照

组件样式与站点 token 一致（圆角大小、边框、阴影都取自 global.css 的实际值）。

③ 半径梯度：从 4px 到 40px

同一块面板在不同圆角大小下的新旧对比。规律：圆角越小差异越难察觉，越大越明显——站内最大用到 24px，整体是「细节更顺」而不是「风格骤变」。

④ 大圆角特写 · 90px

放大到站内不会用到的 90px，纯粹为了把两条曲线的差异看清楚。

如果确认，实际落地长这样

/* global.css */
@supports (corner-shape: superellipse(2)) {
  *, ::before, ::after {
    corner-shape: superellipse(2);   /* 一处声明，全站生效 */
  }
}

corner-shape 不继承，但通配选择器可以一次覆盖所有元素；站内 130 多处 border-radius 一个都不用改。 Chrome / Edge 139+、Firefox 161+ 生效（约七成用户）；Safari 还在技术预览版，会自动回退成现在的 1/4 圆，等它正式支持后无需改动自动生效。 边框、阴影、overflow 裁切都会自动跟随新曲线。
