## 1. 导航栏宽度在不同页面不一致

### 问题描述

首页和工具页的顶部导航栏看起来比关于页的导航栏**更窄**，尽管它们使用的是同一个布局组件 `mainlayout.astro`。

### 现象

- 首页：导航栏看起来较窄
- 工具页：导航栏看起来较窄
- 关于页：导航栏看起来较宽

### 排查过程

1. ❌ 检查 `nav-container` 的 `max-width` 值 — 已统一为 1100px
2. ❌ 检查 `padding` 是否一致 — 都是 `0 1.5rem`
3. ❌ 检查 `scrollbar-gutter: stable` — 不是根本原因
4. ❌ 检查 `* { margin: 0; padding: 0 }` 是否覆盖了样式 — 不是根本原因

### 根本原因

**盒模型（box-sizing）不一致！**

- **首页** `index.css` 中有：`* { box-sizing: border-box; }`
- **关于页** 没有这条规则，使用默认的 `content-box`

### 原理解释

CSS 盒模型有两种计算方式：

```
┌─────────────────────────────────────────────────────────┐
│                     content-box（默认）                  │
│                                                         │
│   width/max-width 只包含内容区域                         │
│   实际占用宽度 = width + padding + border               │
│                                                         │
│   例如：max-width: 1100px + padding: 0 1.5rem           │
│   实际宽度 = 1100px + 24px + 24px = 1148px              │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│                      border-box                         │
│                                                         │
│   width/max-width 包含内容 + padding + border           │
│   实际占用宽度 = width（padding 和 border 计算在内）     │
│                                                         │
│   例如：max-width: 1100px + padding: 0 1.5rem           │
│   实际宽度 = 1100px（padding 已包含在内）                │
└─────────────────────────────────────────────────────────┘
```

所以：
- 首页（border-box）：导航栏总宽度 = 1100px
- 关于页（content-box）：导航栏总宽度 = 1100px + 48px = 1148px

这就是为什么关于页的导航栏看起来更宽！

### 解决方案

在全局样式 `global.css` 中统一设置盒模型：

```css
/* global.css */
* {
  box-sizing: border-box;
}
```

这样所有页面都使用相同的盒模型，导航栏宽度就一致了。

### 最佳实践

1. **始终在全局样式中设置 `box-sizing: border-box`**
   - 这是现代 CSS 的推荐做法
   - 让宽度计算更直观（所见即所得）

2. **避免在多个文件中重复定义全局选择器**
   - 将 `*`、`body`、`html` 等全局规则集中在一个文件
   - 其他页面特定样式只写该页面的类选择器

3. **调试技巧**
   - 使用浏览器开发者工具的 **Computed** 面板
   - 对比不同页面同一元素的计算样式
   - 特别注意 `box-sizing`、`width`、`padding` 这些属性
