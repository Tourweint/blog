# 多鸣的博客（Astro）

一个基于 Astro Content Collections 的静态博客。

## 快速开始

- 安装依赖：`npm install`
- 本地开发：`npm run dev`
- 构建：`npm run build`
- 预览：`npm run preview`

## 文档

- 开发指南（本地开发 / 内容维护）：[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)
- 开发 TODO（按优先级推进）：[docs/TODO.md](docs/TODO.md)

## 内容入口

- 文章目录：`src/content/posts/`
- 文章 frontmatter 校验：`src/content/config.ts`
