# 复盘工具箱：KISS、GRAI、KPT、SMART与PDCA的串联之道

在复盘模型的世界里，除了GRAI，还有一个简洁有力的模型——**KISS**。

## KISS模型：一个清晰的四象限答案

KISS由四个英文单词构成：
*   **Keep（坚持）**：做得好的，要继续保持。
*   **Improve（改进）**：做得不够好，需要优化提升。
*   **Stop（停止）**：不好的、无效的，要立即停止。
*   **Start（开始）**：好的、该做但还没做的，要着手开始。

这个模型内涵简单，但细品之下，它也是**四象限模型**的一种衍生应用。它以“持续性/非持续性”和“评价好/坏”两个维度交叉，得出四种清晰的行动指令：
1.  **持续且好 -> Keep（坚持）**
2.  **持续但不好 -> Improve（改进）** 或 **Stop（停止）**
3.  **未持续但好 -> Start（开始）**
4.  **未持续且不好 -> Stop（停止）**

记性好的就记单词KISS，记性不好的，理解其背后的“逻辑象限”即可。

## 模型辨析：KISS 与 GRAI 有何不同？

同样是复盘模型，KISS与GRAI侧重点不同：
*   **GRAI**（Goal, Result, Analysis, Insight）更强调**总结思路的推进过程**，是一个从目标回溯、分析原因到提炼规律的完整思考流。
*   **KISS** 则更强调**总结结论的清晰化表达**。它实际上是在GRAI的“洞察（Insight）”阶段，提供了一套将杂乱的结论进行归类和落地的行动框架。

因此，这两个模型可以搭配使用。当你用GRAI做完分析，得出一堆纷乱的结论时，可以用KISS的逻辑（坚持、改进、停止、开始）对它们进行分类整理，结论立刻会变得清晰明了。

当然，KISS也可以独立使用。当目标和结果相对简单明确时，可以省略G（目标）和R（结果）的对比过程，直接进行分析和总结。

## 模型关联：KPT 与 目标管理

类似的模型还有**KPT**（Keep, Problem, Try），代表：
*   **Keep（可坚持的）**
*   **Problem（有问题的）**
*   **Try（可尝试的）**

它本质上可以对应KISS中的 **Keep** 和 **Improve/Start**，只是表达逻辑不同，底层思路一致。

KISS虽然是总结模型，但因为它直接导向行动（坚持、改进、停止、开始），所以**面向未来的属性更强**，其结论本身就是下一个阶段目标的雏形。

这时，就需要引入**SMART原则**（具体的、可衡量的、可实现的、相关的、有时限的）来对这些雏形目标进行清晰化处理，使之成为可落地、可执行的具体目标。

## 构建闭环：从复盘中生长出新循环

最终，这个由SMART原则澄清后的目标，将自然导入下一个**PDCA循环**（Plan-Do-Check-Act）的“计划（P）”阶段，开启新的行动、检查与处理。

于是，一个完整的成长闭环便建立起来了：
**行动与实践 (Do/Act) -> 复盘与总结 (GRAI/KISS) -> 提炼与规划 (SMART) -> 新的计划与行动 (PDCA)**。

通过这样的组合运用，我们便能将经验系统化，将洞察行动化，在持续的循环中实现有效的迭代与成长。
