# 飞轮效应：从艰难启动到持续成功的四个阶段

> 飞轮效应这个词被查理·芒格收录在了100个思维模型当中，也在其他的模型中屡次被提到。

## 什么是飞轮效应？

飞轮效应是指为了使静止的飞轮转动起来，一开始你必须花很大的力气，一圈一圈的，每圈都很费力，但是每一圈的努力都不白费，飞轮会转动得越来越快。人在进入某一新的领域时，都会经历这样一个过程。

**简单的理解就是：干什么事吧，刚开始都挺难的，以后跑起来就好了。** 我们老总说的话都讲了话了，说“万事开头难”，就是飞轮效应想表达的重点。

## 飞轮效应的四个阶段

说的深入一点，飞轮效应有四个阶段：

### 1. 确认目标
- **特点**：确认自己做的事是对的，也就是确认发力方向。
- **需要**：洞察。

### 2. 打基础
- **特点**：花大力气却看不到明显效果。
- **需要**：耐心。

### 3. 持续发力
- **特点**：成效不稳定，稍稍放松有可能马上完蛋，努力也可能有等比例的回报，说不好不一定。
- **需要**：坚持。

### 4. 起飞
- **特点**：之前做的功，它的效已经体现出来了。巨大的惯性会让它自己转动很久一段时间，偶尔松油门也没事，再稍微加把力也可以让它转的更快。
- **需要**：惯性保持，偶尔修正。

## 现实应用案例

### 创业经历
1.  **开始方向对了**。
2.  **前期打基础并不容易产生效果**。
3.  **发展期形成规模，拥有核心竞争力**。
4.  **到了一定程度就会运行稳定，扭亏为盈，持续获利**。这时候偶尔有一些懈怠迷茫，也不至于全盘失败。

### 品牌建设
1.  **开始策略对了**。
2.  **前期投入费用高，收效不明显**。
3.  **中期持续发力，让品牌深入人心**。
4.  **后期就可以通过品牌溢价获利**，即便偶尔遇到一点公关危机，也不会那么容易崩塌。

### 个人学习提升
1.  **前期打基础看不出效果**。
2.  **中期坚持成绩时好时坏**。
3.  **但只要积累到一定程度，后期就会稳定在一个高水平的位置**。
4.  **平时只要稍微观察一下最新知识、前沿成果，就可以持续保持领域内的领先地位**。

## 飞轮效应的核心价值

在我看来，飞轮效应并不像其他思维模型那样能为我们解决什么具体问题，但是它能提醒我们**如何理解一个问题**，就是当你感到坚持做一件事情又难又没效果的时候，就可以想想这件事未来可不可以形成飞轮效应。这能让一个人在对待正确的事情上更有耐心，更能坚持。
